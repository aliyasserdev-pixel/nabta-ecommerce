# 🌱 نَبْتة — متجر الزراعة المنزلية

متجر إلكتروني عربي متخصص في مستلزمات الزراعة المنزلية.

## الحالة
🚧 المشروع قيد التطوير — المرحلة 1: هيكل المشروع

## التقنيات
- Frontend: React + Vite (JavaScript)
- Backend: Node.js + Express
- Database: PostgreSQL (سيتم إضافتها لاحقًا)

## التشغيل السريع

### Backend
\`\`\`bash
cd server
npm install
npm run dev
\`\`\`

### Frontend
\`\`\`bash
cd client
npm install
npm run dev
\`\`\`
